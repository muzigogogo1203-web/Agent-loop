# Blocked — 窗口尺寸适配整体优化

日期：2026-07-14

## 阻塞原因

用户反馈最新版 Coding 牧场在调整窗口大小时存在多处 UI 错位，并要求整体优化。

当前 `plan.md` 只规定了窗口最小宽度 640，以及 Coding 牧场 MVP 的页面范围；没有定义本轮响应式适配所需的决策与验收标准，包括：

- 需要正式支持和验收的窗口宽度、高度及全屏尺寸；
- `NavigationSplitView` 在窄窗口下应保持双栏、自动折叠，还是切换为单栏导航；
- 营地首页、Coding 草原、回营、牛群、设置与各类 sheet 在窄/中/宽窗口下的布局规则；
- 固定宽度、最小宽度、优先级压缩、滚动和文字截断的统一策略；
- 本轮允许修改的具体文件，以及是否允许调整导航与交互；
- UI 验收方式（尺寸矩阵、截图或 UI 测试）和完成定义。

## 需要规划方补充

请为本次窗口适配新建或补充一份决策完备的实施计划，至少列出：

1. 支持的窗口尺寸矩阵和每个断点的预期行为；
2. 各主页面及 sheet 的布局规则；
3. 允许触及的文件清单；
4. 需要增加的测试或可重复的视觉验收步骤；
5. 明确的完成门槛。

计划补齐前不修改产品 UI，以避免擅自决定导航、布局和交互行为。
