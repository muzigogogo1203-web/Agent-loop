P0 privacy scan
Date: 2026-07-25
Scope: all P0 text deliverables (root guidance, protocol, master/historical
specs, and docs/collaboration/tasks/2026-07-25-personal-ai-ranch-p0)

Method
------
All P0 text deliverables and non-JPEG task artifacts were scanned with ripgrep
PCRE2 patterns for:

1. credential-shaped values (`sk-…`, long Bearer values, OAuth/API key query values);
2. email addresses;
3. HTTP(S) URLs containing query strings;
4. session/account/credential labels followed by concrete long values.

The output file itself was excluded so the documented patterns cannot match
their own description. Matches, if any, were counted by filename without
printing candidate secret values.

Executed command shape (repeated once per pattern):

    task_dir='docs/collaboration/tasks/2026-07-25-personal-ai-ranch-p0'
    root_files=(AGENTS.md CLAUDE.md README.md
      docs/collaboration/claude-codex-protocol.md
      docs/superpowers/specs/2026-07-04-agentloop-macos-mvp-design.md
      docs/superpowers/specs/2026-07-06-agentloop-v2-design.md
      docs/superpowers/specs/2026-07-15-coding-ranch-visual-design.md
      docs/superpowers/specs/2026-07-25-personal-ai-ranch-master-spec.md)
    { printf '%s\0' "${root_files[@]}"
      find "$task_dir" -type f ! -name '*.jpg' ! -name 'privacy-scan.txt' -print0
    } |
      xargs -0 rg -l --pcre2 '<pattern>' |
      sort -u |
      wc -l

The exact four PCRE2 patterns were:

    (?i)(sk-[A-Za-z0-9_-]{16,}|bearer\s+[A-Za-z0-9._~+/-]{16,}|(?:access_token|refresh_token|api_key|oauth_code|authorization_code|state|code)=[A-Za-z0-9._~+/%-]{8,})
    (?i)[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}
    https?://[^[:space:]<>"`?]+\?[^[:space:]<>"`]+
    (?i)(?:session|account|credential)[^\r\n]{0,40}[=:][[:space:]]*[A-Za-z0-9._~+/-]{12,}
