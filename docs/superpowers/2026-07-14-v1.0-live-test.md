## 第 1 组 · 首启与牧场 Golden Path(牧场 MVP 核心)

1. 全新状态目录首启:出现「我的营地」、营地管家、基础牛;首跑欢迎页可进营地。☐
2. 喂牛:粘贴一段技术文章 → 待反刍区出现条目(阶段展示真实推进);重复粘贴同文 → 重复提示。☐
3. 反刍确认:检查页可编辑标题/要点/需求 → 确认后生成带来源的营地笔记 + 建议任务。☐
4. 放牛:从建议任务生成草稿(验收清单/来源笔记可见)→ 出发 → 基础牛完成 → 回营验收。☐
5. 领牛:满足 5 条件后测试牛可领回,重复领取幂等(不出现第二头)。☐
