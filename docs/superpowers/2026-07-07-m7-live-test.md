# M7「哨卡」正式测试脚本（用户执行，真实 API）

> 前置：m4/m5/m6 tag 已打；工作树切到 feat/m7；`scripts/run-app.sh` 启动（真实数据）。
> 全部通过后打 `m7` tag。任何一步不符请记录现象（截图 + 大致时间），我来修复。

## 1. 审批门主线（标准档 + shell）

1. 设置页确认「默认自主档位 = 标准」。
2. 建一个绑定工作目录的行动：「clone https://github.com/apple/swift-argument-parser 并跑通测试，写一份结果笔记」。
3. **验收**：伙伴调用「跑命令」时卡片挂起、行动列表琥珀高亮；审批弹卡**展示命令全文（等宽字体）**；点「批准」→ 卡片续跑、命令真实执行；最终交付笔记落盘。
4. 让伙伴再跑一条危险命令（或等它自己跑第二条不同命令）→ **每条新命令都重新审批**（参数变了令牌不复用）。

## 2. 拒绝改道

1. 同类行动中，对某条审批点「拒绝」，理由填「不要动这个目录」。
2. **验收**：卡片继续跑（不再挂在原地），伙伴收到拒绝理由后换做法或用 block_card 说明；活动时间线可见这次拒绝。

## 3. 谨慎档与放手档

1. 新行动选「谨慎」：伙伴**写文件**也要审批（弹卡显示写入路径与内容）。
2. 新行动选「放手」：写文件、跑命令全不弹窗，一路到收营（预算是唯一护栏）。
3. 行动进行中把档位从「标准」改成「放手」→ 后续危险操作不再弹（档位签即时更新）。
4. **专项盯审批疲劳**：标准档跑一个正常开发任务，弹窗频次是否可忍受？如果体验退化成「全部弹窗」记录感受，我调默认矩阵。

## 4. 紧急收哨

1. 发起一个多卡行动，执行中点「收哨」（或 Cmd+.）。
2. **验收**：全部行动即停、横幅出现；`ps` 里无残留 zsh 子进程；点「恢复出哨」→ 中断的小目标自动续跑到完成；事件时间线含收哨/恢复记录。
3. 进阶：收哨状态下完全退出 App 重开 → 行动仍暂停？（收哨标志是内存态，重启后回到正常调度——这是预期行为，确认不惊讶即可。）

## 5. 花销分账

1. 跑完一个 ≥2 伙伴的行动，点头部「花销 ~Nk」签。
2. **验收**：浮层按伙伴分账 + 向导规划一行 + 合计/预算；数字与预算指示一致（口径=本地估算）。

## 6. 429 冷却（机会性观察）

网关限流时（若遇到）：feed/事件里出现限流冷却记录、随后自动恢复派发——不必刻意制造。
