# M3 Live Test Script

1. Create a three-companion mission with independent subtasks. Confirm at least two companions show running/working at the same time.
2. Create a goal that requires clarification. Confirm the waiting card is pinned/highlighted, the feed shows a question, answer once from the card row and once from the feed in separate runs, and the resumed output uses the answer.
3. Watch the activity feed and theater while a mission runs. Confirm feed entries match card progress, theater states match the current mission list, and animations pause when the app loses focus.
4. Open a card detail inspector. Check timeline, handoff, run history, artifacts, and raw developer fields; reveal an artifact in Finder if present.
5. Close out a delivering mission. Switch between recent missions in the sidebar and confirm the central view does not jump to another mission; right-click a non-current running/stuck mission and abandon it.
6. Enable Reduce Motion and repeat the theater/feed check. Avatars, campfire, and map should render static states with no pulse or distracting motion.
7. Optional resilience check: disconnect the network or stall a provider turn beyond the idle deadline. The card should retry once, then move to waiting/blocked instead of staying running forever; slow streams that keep producing events should not time out.
