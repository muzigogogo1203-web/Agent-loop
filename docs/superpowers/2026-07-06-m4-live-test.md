# M4 正式测试脚本 — 知识与对话层（营地笔记 / 伙伴记忆 / 向导）

前置：`swift run AgentLoopApp`（真实 API key 已配置）。基线：feat/m4，197 离线测试全绿。
验收目标（spec §16-M4）：**私聊沉淀的记忆出现在该伙伴下一次工作上下文；向导对话一键组队开工；跨行动经验复用可演示。**

## 1. 收营蒸馏 → 营地笔记

1. 跑一个小行动（1-2 卡）到全部完成，点「收营」。
2. 进侧栏「营地」→ 营地首页：左侧笔记本应出现一条蒸馏笔记（标题 ≤30 字，正文含「做了什么/什么做法有效/关键产物在哪/踩了什么坑」四节；带「收营」标签）。
   - 若蒸馏 LLM 调用失败，应出现回退拼接笔记（交接包 outcome+summary 逐卡拼接）——无论如何**必有一条笔记**。
3. 点笔记行 → 编辑弹窗：改标题/正文保存、置顶、删除各试一次。

## 2. 跨行动经验复用（验收 ③）

1. 新开一个相关主题的行动。
2. 观察规划质量/卡片产出是否引用了上一条笔记的经验（伙伴发言或产物中可见；或按 1 里置顶的笔记全文注入）。

## 3. 私聊沉淀 → 记忆 → 下一卡（验收 ①）

1. 与某伙伴私聊几轮**有信息量**的对话（如约定交付格式）。
2. 点工具栏「沉淀记忆」→ 转菊花 → toast「已记住这段对话」；点「记忆」打开右侧抽屉，确认条目出现。
3. 给该伙伴派一张相关卡 → 其产出应体现记忆内容（或从行为可推断记忆生效）。
4. 也试一次无信息量的对话（寒暄两句）→ 沉淀 → 应 toast「暂时没什么要记的」且不产生条目。

## 4. 切走自动沉淀（D7）

1. 与伙伴私聊 ≥4 条新消息（不点沉淀按钮）。
2. 切去设置页再切回来 → 稍候记忆抽屉应出现新条目（产出时有 toast「这段私聊已沉淀为记忆」；若模型判定无内容则无条目、不再重复送蒸）。

## 5. 向导对话 + 一键组队（验收 ②）

1. 营地首页右侧问向导：「营地最近情况怎么样？」→ 应看到「向导看了看营地各处…」工具活动行 → 回复引用真实行动状态（camp_status）。
2. 问「上次 XX 的经验是什么」→ 向导应翻笔记（search_camp_notes）。
3. 说「帮我组个队做 XX」→ 出现**组队提案卡片**（小队名/成员头像/目标/预算 + 琥珀「等你拿主意」）。
4. 点「就这么办」→ 卡片变「已开工」→ 自动跳转到新行动页，行动开始规划执行。
5. 回营地首页**再点一次同一提案**（若还能点）→ 应提示「这个提案已经处理过了」，不重复建队。
6. 让向导再拟一个提案 → 点「先不」→ 卡片淡化为「已搁置」。
7. 重启 App → 营地首页历史里提案卡片状态保持（confirmed 的仍可跳转）。
8. 点「沉淀笔记」→ 对话增量应蒸馏为一条营地笔记（「手记」标签）。

## 6. 网关韧性（第 0 步改动的实战面）

1. 找一个会产出长文件的任务（>3000 字）→ 观察伙伴是否分多次 write_file（append 续写），不再单轮巨型生成。
2. 若网关断流，UI 应显示重试且最终成功（非流式兜底 + 放宽的重试间隔 [2,5,10,20]s）；不应再出现单卡连挂多个 run。

## 7. Reduce Motion / 窄窗口

1. 系统开「减弱动态效果」→ 营地首页/提案卡片/记忆抽屉全部静态替代、功能不损。
2. 窗口收窄 → 笔记本自动收起（保留切换钮）；DM 记忆按钮禁用并提示加宽。
