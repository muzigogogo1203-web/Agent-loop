# M6「斥候」正式测试脚本（用户执行，真实 API）

> 前置：M4/M5 正式测试已过、m4/m5 tag 已打（收官门）；主仓或工作树切到 feat/m6。
> 启动：`scripts/run-app.sh`（真实数据）。全部通过后打 `m6` tag。
> 任何一步不符请记录现象（截图 + 大致时间），我来修复。

## 1. 斥候出门（web_search 主线）

1. 设置页 →「联网搜索（Tavily）」→ 填入你的 Tavily key 保存 → 出现「已配置」徽章。
2. 新建伙伴「斥候」，工具区确认「联网搜索」可勾且默认勾上（key 配好后不再置灰）。
3. 对斥候发起行动：「调研 2026 年主流桌面 AI Agent 产品最新动态，写一份对比报告」。
4. **验收**：行动过程可见「正在联网搜索…」活动行；交付物报告含**近期真实来源（可点开核实的 URL）**；Finder reveal 正常。

## 2. 白名单生效

1. 再建伙伴「文书」，工具区**取消勾选**「联网搜索」与「写文件」保存。
2. 对文书发起需要联网的行动（如「查一下今天 Swift 官方博客的最新文章标题」）。
3. **验收**：文书调用 web_search/write_file 被拒（活动行「联网搜索失败」类反馈），最终它用 block_card 或纯文字交接说明局限；全程行动不死；重开编辑器，勾选状态与保存一致。

## 3. 无 key 自然降级

1. 设置页移除 Tavily key。
2. **验收**：伙伴编辑器「联网搜索」置灰 +「先到设置页配置 Tavily key」提示；此时发起的行动中，伙伴提示词里没有 web_search（表现为它不会尝试联网搜索）。

## 4. 模型目录与三档模型

1. 设置页「模型」→ 加入一个你网关可用的模型 id → 出现在伙伴编辑器 Picker。
2. 改「默认模型」→ **完全退出 App 重开** → 不复位（这是修掉的 bug）。
3. 「蒸馏用模型」选一个轻量模型 → 跑一个小行动到收营 → 营地笔记正常生成（蒸馏走轻模型，可从网关后台/费用侧核实）。
4. 移除目录里的当前默认模型 → 默认模型自动落到目录首项，无空选。

## 5. 规划轮入账

1. 发起一个新行动，规划完成、**第一张卡还没跑完之前**看行动详情/预算指示。
2. **验收**：已花费 tokens > 0（规划的钱入账了）；行动事件流里有规划相关记录。

## 6. 向导回归（并入 M4 对抗评审的实战面）

1. 营地首页与向导对话：翻笔记（search_camp_notes）、看营地（camp_status）、让它提组队提案 → 确认建队开工。
2. **验收**：三个工具行为与 M4/M5 时一致（分发机制换成 ToolExecutor 的纯重构回归）；提案确认幂等（双击确认不重复建队）。

## 7. Reduce Motion 复核（惯例项）

系统开启「减弱动态效果」→ 新增的设置页/编辑器区块无异常动效残留。
